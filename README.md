# Python Calculator

A small desktop calculator built with Python and Tkinter. Its button-driven interface supports addition, subtraction, multiplication, division, parentheses and clearing the current calculation.

## Run locally

Use Python 3 with Tkinter available:

```sh
python3 main.py
```

The application opens a desktop window. It requires a graphical desktop session; Tkinter is part of many Python installations and may need the platform’s Tk package on others.

## Inside the project

`main.py` contains the complete application: the Tkinter window, button grid, expression state, calculation and clear actions. It is an early GUI learning project.
